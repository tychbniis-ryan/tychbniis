Workflow

建議流程

  1. 1

    本機確認

    先開啟本機測試網址，確認網站畫面與文字內容正確。

  2. 2

    連結 GitHub

    建立 GitHub repository 後，設定 remote 並推送到 GitHub。

  3. 3

    啟用 GitHub Pages

    在 GitHub repository 的 Pages 設定中選擇 `main` 分支發布。

Maintenance

維護原則

每次修改需同步更新

  • `CHANGELOG.md`
  • `docs/AI_HANDOVER.md`
  • `app/modules/website/version.py`

不得提交到 GitHub

  • 帳號、密碼、Token、Cookie
  • 含個資的 Excel、CSV 或截圖
  • 機關內部未公開文件
