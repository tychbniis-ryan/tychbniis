# 第 5 版視覺優化紀錄

日期：2026-05-28

版本：`0.5.16`

## 0.5.16 學員端結算、道具文字與排行榜修正

1. 道具清單與道具使用紀錄改為短文字，分數效果以右側像素標籤呈現。
2. 加倍卡提示文字改為下題答對加倍，不再誤顯空寶箱。
3. 挑戰卡彈窗採手機優先單欄排版，挑戰結果改為滿寬像素風卡片。
4. 學員端排行榜精簡資訊並補上序位獎盃圖示。
5. 最後成績改為任務結算風格，結算後隱藏作答區並同步頂欄個人分數。

## 0.5.15 講師端確認視窗修正

1. 講師端結算競賽、清空測試資料與重新開題，不再使用瀏覽器原生 `confirm()`。
2. 以上 3 個確認流程改為遊戲內像素風對話框，避免畫面顯示網址通知。
3. 危險操作使用較醒目的提示色，保留取消與確認兩個明確按鈕。
4. 本版只修改講師端前端 UI，不修改 GAS 計分、寶箱、道具或結算規則。

## 0.5.14 講師端初始化、挑戰卡揭曉與標籤置中修正

1. 講師端重新載入時，若 GAS 場次狀態已回到 `draft`，會直接回到「啟動場次」頁面。
2. 講師端流程標題移除標號，顯示為「啟動場次」與「題目控制」。
3. 成就狀態標籤改為水平與垂直置中，改善「已領取」與「進行中」顯示。
4. 挑戰卡抽號後會先停在號碼揭曉畫面，學員可點擊「揭曉結果」，或等待 5 秒自動顯示成功、失敗或放棄結果。

## 0.5.13 遊戲確認視窗、寶箱機率與全對獎區塊修正

1. 學生端送出答案與放棄創作，改為遊戲內像素風確認視窗，不再使用瀏覽器原生 `confirm()`。
2. 寶箱獎勵機率調整為空寶箱 5%、翻身卡 5%、挑戰卡 20%，同步更新靜態設定與 GAS 預設規則。
3. 翻身卡每位學員最多抽到 1 張；同隊第 2 次使用翻身卡時，效果為 +10 分。
4. 投影端結算獎項區塊允許全對獎名單換行，不因第 2 行被畫面裁切。

## 0.5.11 UI 文字、寶箱流程與投影端結算修正

1. 報到頁自由選隊時隱藏「進入報到」按鈕，讓學員輸入暱稱後直接點選戰隊完成報到。
2. 學員端作答區移除開始作答說明文字、場次啟動重複提示、排行榜快照系統說明、寶箱與成就更新提示。
3. 寶箱彈窗標題依功能顯示為「寶箱」或「成就」，不再共用「寶箱與成就」。
4. 未開啟寶箱改用關閉狀態圖；空寶箱開啟後列入道具使用紀錄，使用原本開箱圖示。
5. 道具使用紀錄加入道具圖示，並以單行顯示道具名稱、結果與套用狀態。
6. 道具說明改為操作語意，例如「可立即增加個人道具分 3 分」。
7. 作答送出後改為「防線已部署，等待講師公布結果」畫面，避免保留不可修改的題目與選項。
8. 投影端結算畫面隱藏上方主視覺圖，避免幸運獎與全對獎被切到；個人排名最多顯示 5 名，且每名都有數字意象圖。
9. 講師端初始化文案改為「清空測試資料」，本版選擇沿用刪除舊資料流程，不導入場次版本控制。
10. 本版截圖位於 `screenshots/v5_0_5_11/`，包含自由選隊、送出作答、關閉寶箱、道具紀錄、成就與投影端結算畫面。

## 0.5.10 狀態顯示簡化修正

1. 移除投影端「目前狀態」前方的循環箭頭圖示。
2. 移除學員端、講師端與投影端狀態文字中的循環箭頭 loading 圖示。
3. 移除學員端與講師端狀態文字下方的綠橘條紋等待動畫。
4. 移除講師端流程狀態左側的綠橘垂直條紋動畫，改為單色高亮。
5. 等待後台回應時改以純文字狀態呈現，避免固定 UI 元件出現不必要的動畫干擾。
6. 已移除 `frontend/` 內的 `reload.svg` 靜態圖示檔，並確認不再引用 `--icon-reload`、`var(--icon-reload)` 或 `loading-stripes`。

## 0.5.9 視覺資產、成就排版與挑戰卡圖像修正

1. 學員端成就頁改為固定欄位排版，每個成就都有對應任務圖示，避免圖示、文字與狀態按鈕重疊。
2. 學員端道具卡改為每種道具使用不同圖片，包含 +1、+3、+5、+10、加倍、翻身、挑戰與空箱。
3. 挑戰卡補齊猜大、猜小、放棄猜測、0 到 9 抽號碼卡，以及成功、失敗、放棄結果圖。
4. 戰隊顯示改用真實隊名，學員端不再顯示「第幾隊」或內部代碼。
5. 投影端排行榜獎盃規則調整為第 1 名彩虹、第 2 名紫色、第 3 名金色、第 4 名銀色、第 5 名銅色。
6. 全對獎與幸運獎改用獨立圖像，不與排名獎盃共用；全對獎強化全對清單與皇冠語意，幸運獎強化幸運草、骰子與紫色獎盃語意。
7. 本版截圖位於 `screenshots/v5_0_5_9/`，用於檢查成就、道具、挑戰卡與排行榜畫面。

## 0.5.8 學員體驗、像素圖示與翻身卡修正

1. 依使用者回饋移除報到與等候狀態的自轉方塊，改用 PixelArt Icons 的 SVG 圖示與像素條紋等候效果。
2. 學員答題介面移除不必要圖片，避免題目閱讀區被裝飾圖干擾。
3. 學員端分數列移除「道具加分」欄位，只保留個人積分、戰隊與排行榜，降低答題時的資訊負擔。
4. 成就清單每筆成就加入像素圖示，並優化「領取」、「已領取」、「進行中」、「完成」的按鈕與狀態樣式。
5. 挑戰卡加入 0 到 9 抽號碼動畫，結果畫面分為挑戰成功、挑戰失敗與放棄猜測。
6. 投影端改為像素風格背景、卡片、選項、排行榜與獎項樣式，維持與學員端一致的視覺語言。
7. 排行榜對使用者顯示正式隊名，不顯示 `team_1` 這類內部代碼。
8. 翻身卡邏輯改為只有唯一最後 1 名取得 30 分，其餘情形取得 5 分。
9. 本版新增 `pixelarticons` npm 依賴，靜態 SVG 放在各端 `dist/assets/icons/pixelarticons/`。
10. 功能狀態快照位置：`screenshots/v5_0_5_8/`。
11. GAS 已推送並更新既有 Web App deployment 到 `@52`。
12. Firebase Hosting 已部署完成，線上學員端、講師端與投影端均載入 `0.5.8` 前端資源。
