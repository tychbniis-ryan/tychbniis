# 第 5 版視覺優化紀錄

日期：2026-05-29

版本：`0.5.23`

## 0.5.23 挑戰卡、寶箱分配與個人獎牌修正

1. 挑戰卡數字牌改用 `challenge-number-v523-0.png` 至 `challenge-number-v523-9.png`，每張牌四邊保留透明安全距離，避免切到旁邊卡片。
2. 挑戰卡選大或選小後進入 5 秒抽號動畫，可手動停止或自動停止，停在預設號碼 3 秒後自動結算。
3. 挑戰卡結算畫面會顯示成功或失敗圖，以及剛才抽中的數字牌；不猜直接結算，不顯示數字牌。
4. 講師端追加寶箱恢復為只啟用點選箱號，不再自動啟用前面箱號。
5. 追加寶箱與落後寶箱改用玩家種子與寶箱權重抽取內容物，避免全員獎勵一致。
6. 個人排行改用 `award-player-medal-v523-1.png` 至 `award-player-medal-v523-5.png` 獎牌，第 1 至第 5 名依序為彩色、紫、金、銀、黃。
7. 學員端與投影端排行榜改讀新獎牌檔名，避免瀏覽器沿用舊圖。
8. 依 frontend-design 原則檢查本次互動，讓抽號動畫、停止按鈕與結算資訊有明確遊戲狀態。
9. 挑戰卡抽號動畫高亮改為藍色對比底與外框，停住結果改為綠色確認狀態，避免黃色數字牌在黃色底色上不明顯。
10. 結算後學員端頂欄個人積分改以後端最終分數為準，避免與排行榜快照不同。
11. GAS 最後成績查詢改為只讀已結算結果，避免非第 1 名學員讀取時觸發空範圍錯誤。
12. GAS Web App deployment 更新為 `@59`；Firebase Hosting 已部署。

## 0.5.20 講師端入口與個人獎盃修正

1. 講師端根網址 `/` 已同步為與 `/Instructor.html` 相同的控制台 UI。
2. 根網址控制台會顯示第 1 箱至第 5 箱追加寶箱按鈕，以及落後寶箱戰隊選擇與啟用按鈕。
3. 個人排名獎盃第 1 名至第 5 名已重製為透明背景 PNG，移除綠色底圖元素。
4. 本版只需部署 Firebase Hosting，GAS Web App deployment 維持 `@57`。

## 0.5.19 寶箱開關與排行榜修正

1. 追加寶箱改為第 1 箱至第 5 箱的明確啟用按鈕，降低講師端判斷與等待成本。
2. 新增落後寶箱啟用流程，講師選擇戰隊後，該戰隊學員端依固定規則取得預分配寶箱。
3. 追加寶箱與落後寶箱僅更新寶箱狀態欄位，不更新場次 `updatedAt`，避免未開題時學員端被強制登出。
4. 重新處理未開啟寶箱與個人排行獎盃圖片去背，移除亮綠色底圖與綠邊。
5. 放大投影端排行榜文字，並修正學員端排行榜標題與更新按鈕卡位。

## 0.5.18 取消試玩功能與追加寶箱優化

1. 移除講師端「開放試玩題」與「清除試玩紀錄」，回到正式題既有流程。
2. 若需要試玩，改由講師在題庫自行設定試玩題，試玩後使用「清空測試資料」再進入正式題。
3. 講師端「發送寶箱」改為「啟用追加寶箱」，每按一次啟用 1 個追加寶箱，最多 5 個。
4. 追加寶箱改由 Firebase 公開狀態啟用，學員端本機依固定槽位補入寶箱，避免逐一寫入 Google Sheets 造成等待。
5. 個人排名獎盃與未開啟寶箱圖示移除綠幕底色，排行榜圖示縮小避免互相裁切。
6. 自由選隊隊名改為上 2 字、下 3 字，避免「隊」字單獨斷行。

## 0.5.17 試玩題與即時發送寶箱
1. 講師端新增「發送寶箱」，可重複讓所有目前學員取得 1 個未開啟寶箱。
2. 講師端新增「開放試玩題」，使用既有題目建立 `trial_` 題號，學員照正常答題流程操作。
3. 學員答對試玩題會立即計入目前積分並取得 1 個寶箱，但不進入幸運獎與全對獎。
4. 講師端新增「清除試玩紀錄」，正式題開始前可清除試玩答題、試玩寶箱、試玩道具與分數影響。
5. 清除試玩紀錄後，學員端會同步清除本機試玩資料，避免試玩分數殘留在頂欄。

## 0.5.16 學員端結算、道具文字與排行榜修正

1. 道具清單與道具使用紀錄改為短文字，分數效果以右側像素標籤呈現。
2. 加倍卡提示文字改為下題答對加倍，不再誤顯空寶箱。
3. 挑戰卡彈窗採手機優先單欄排版，挑戰結果改為滿寬像素風卡片。
4. 學員端排行榜精簡資訊並補上序位獎盃圖示。
5. 最後成績改為任務結算風格，結算後隱藏作答區並同步頂欄個人分數。

## 0.5.15 講師端確認視窗修正

1. 講師端結算競賽、清空測試資料與重新開題，不再使用瀏覽器原生 `confirm()`。
2. 以上 3 個確認流程改為遊戲內像素風對話框，避免畫面顯示網址通知。
3. 危險操作使用較醒目的提示色，保留取消與確認兩個明確按鈕。
4. 本版只修改講師端前端 UI，不修改 GAS 計分、寶箱、道具或結算規則。

## 0.5.14 講師端初始化、挑戰卡揭曉與標籤置中修正

1. 講師端重新載入時，若 GAS 場次狀態已回到 `draft`，會直接回到「啟動場次」頁面。
2. 講師端流程標題移除標號，顯示為「啟動場次」與「題目控制」。
3. 成就狀態標籤改為水平與垂直置中，改善「已領取」與「進行中」顯示。
4. 挑戰卡抽號後會先停在號碼揭曉畫面，學員可點擊「揭曉結果」，或等待 5 秒自動顯示成功、失敗或放棄結果。

## 0.5.13 遊戲確認視窗、寶箱機率與全對獎區塊修正

1. 學生端送出答案與放棄創作，改為遊戲內像素風確認視窗，不再使用瀏覽器原生 `confirm()`。
2. 寶箱獎勵機率調整為空寶箱 5%、翻身卡 5%、挑戰卡 20%，同步更新靜態設定與 GAS 預設規則。
3. 翻身卡每位學員最多抽到 1 張；同隊第 2 次使用翻身卡時，效果為 +10 分。
4. 投影端結算獎項區塊允許全對獎名單換行，不因第 2 行被畫面裁切。
