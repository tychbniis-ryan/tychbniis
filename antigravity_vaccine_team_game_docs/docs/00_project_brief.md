# 00 專案概要

## 專案名稱

疫苗守護戰隊挑戰賽

## 課程情境

- 課程：預防接種教育訓練
- 對象：醫事人員
- 時間：120 分鐘
- 人數：約 200 人
- 分組：5 個戰隊
- 題數：建議 9 至 11 題
- 創作票選題：1 題

## 核心目的

透過即時問答、戰隊競賽、寶箱、道具、成就與匿名創作票選，提升醫事人員在預防接種教育訓練中的參與度、注意力與實務判斷能力。

## 三方分工

| 系統 | 分工 |
|---|---|
| GitHub | 專案文件、程式碼、Issue、版本管理 |
| Firebase | 前端部署、登入、即時狀態、資料庫、後端函式 |
| GAS / Google Sheets | 題庫設計、場次設定、題庫同步、賽後報表 |

## 課程節奏

| 時間 | 課程內容 | 遊戲設計 |
|---|---|---|
| 0-10 分鐘 | 開場、掃碼、分隊 | 報到與規則說明 |
| 10-30 分鐘 | 預防接種核心概念 | 2 題快問快答 |
| 30-50 分鐘 | 接種前評估、禁忌、流程 | 2 題選擇題或排序題 |
| 50-60 分鐘 | 前半段小結 | 排行榜與寶箱使用 |
| 60-80 分鐘 | 冷鏈、保存、紀錄、異常處理 | 2 題情境題 |
| 80-100 分鐘 | 接種後觀察、不良事件、溝通 | 1 至 2 題高分題 |
| 100-110 分鐘 | 接種情境創作題 | 隊內初選、匿名票選 |
| 110-118 分鐘 | 最終決戰 | 綜合情境題 |
| 118-120 分鐘 | 頒獎 | 戰隊與個人獎項 |
