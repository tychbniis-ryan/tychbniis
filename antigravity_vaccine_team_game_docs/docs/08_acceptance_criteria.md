# 08 驗收條件

## 基本功能

- [ ] 學員可用手機掃 QR Code 進入。
- [ ] 學員可匿名登入。
- [ ] 學員可輸入暱稱。
- [ ] 系統可自動分配 5 個戰隊。
- [ ] 講師可開放與關閉題目。
- [ ] 學員每題只能作答一次。
- [ ] 題目關閉後不可再作答。
- [ ] 答案送出後不可修改。
- [ ] 學員端不會取得正確答案。

## 計分

- [ ] 可依時間區間計算基礎分。
- [ ] 可判定首答獎勵。
- [ ] 個人分數可加入戰隊。
- [ ] 戰隊可依加權平均分排名。
- [ ] 可重新計分。
- [ ] 可手動修正分數。

## 寶箱與道具

- [ ] 答對題目可依 30% 機率取得寶箱。
- [ ] 成就可發送寶箱。
- [ ] 每人寶箱最多 3 個。
- [ ] 超過 3 個時自動丟棄最早未開啟寶箱。
- [ ] 可開出加分卡、加倍卡、翻身卡、挑戰卡、特殊道具。
- [ ] 幸運獎只會產生 1 名。
- [ ] 幸運獎產生後特殊道具不再出現。

## 獎項

- [ ] 全對獎只取 3 名。
- [ ] 全對獎依完成時間排序。
- [ ] 幸運獎只取 1 名。
- [ ] 可產出得獎名單。

## 創作票選

- [ ] 每位學員可提交 1 則創作答案。
- [ ] 隊內初選限時 60 秒。
- [ ] 每隊可產生前 3 名候選。
- [ ] 講師每隊選 1 則。
- [ ] 最終作品匿名顯示為作品 A-E。
- [ ] 全體投票限時 60 秒。
- [ ] 後端可限制不可投自己隊。
- [ ] 可依票數加分。

## Google Sheets / GAS

- [ ] 使用者可在 Google Sheets 設計題庫。
- [ ] GAS 可驗證題庫欄位。
- [ ] GAS 可同步題庫至 Firebase。
- [ ] GAS 可將正確答案寫入受保護區域。
- [ ] GAS 可匯出作答紀錄。
- [ ] GAS 可匯出戰隊成績、個人成績、得獎名單。
