# 01 遊戲規則

## 第 6 版計分補充

第 6 版計分以「第 N 次關題」為基準，不以題目題號大小為基準。講師可以不照題號順序出題。

計分規則：

1. 第 1 次關題後，只計算第 1 次出題的回答分數。
2. 第 2 次關題後，只計算第 2 次出題的回答分數，並納入第 1 次關題後使用的道具分數。
3. 之後依此類推：第 N 次關題時計算第 N 次出題的回答分數，並納入第 N-1 次關題後使用、應在本次結算的道具分數。
4. 道具使用紀錄需標記 `usedAfterQuestionSequence` 與 `settleAtCloseSequence`，讓 GAS 可依實際關題次序結算。
5. 本機端與 Firebase 不應每次重送整場資料；學員端送答只送本題回答資料，道具只送本次使用紀錄。
6. 若講師誤觸同一題關題 2 次，關題次序不增加；例如第 4 次關題為題號 5，再次關題仍視為第 4 次關題，不得變成第 5 次。
7. 本機端判斷第幾次關題時，同樣讀取 `openedQuestionIds` 的實際開題順序並去重，再用題號所在位置判斷次序。

## 第 4 版定版狀態

第 4 版已於 2026-05-27 以 `0.4.28` 定版。定版文件為 `docs/16_v4_final_release.md`。

第 4 版採用靜態 HTML5 優先、低 GAS 呼叫、免費方案穩定架構。學員端負責本機即時計算與體驗，GAS 負責紀錄、去重、關題計分、排行榜快照、最後道具同步、幸運獎、全對獎與賽後報表。

## 基本設定

| 項目 | 規則 |
|---|---|
| 戰隊數 | 5 隊 |
| 學員人數 | 約 200 人 |
| 主要勝利條件 | 戰隊積分最高 |
| 幸運獎 | 1 名 |
| 全對獎 | 3 名，最快完成且全數答對 |
| 寶箱上限 | 每人最多 3 個 |
| 投票時間 | 60 秒 |

## 戰隊勝利條件

```text
戰隊積分 = 各題答題平均分加總 + 全隊道具加分
```

各題答題平均分 = 該題所有作答者答題得分 / 該題參與人數。排行榜不顯示答對率。

## 答題計分

| 答對時間 | 個人基礎分 |
|---|---:|
| 0-10 秒 | 30 |
| 11-20 秒 | 25 |
| 21-30 秒 | 20 |
| 31-45 秒 | 15 |
| 46-60 秒 | 10 |
| 截止前答對 | 5 |
| 答錯或未答 | 0 |

第 4 版取消首答獎勵，避免關題時額外進行即時排序與加分計算。
講師開題後學員端倒數為 65 秒。剩餘 65 到 60 秒皆記為 1 秒；剩餘 59 秒時記為 1 秒，剩餘 58 秒時記為 2 秒，依此類推。

## 寶箱

### 取得條件

| 條件 | 獎勵 |
|---|---|
| 每題答對 | 30% 機率取得 1 個寶箱 |
| 正確回答 3 題 | 1 個寶箱 |
| 正確回答 5 題 | 1 個寶箱 |
| 正確回答 10 題 | 2 個寶箱 |
| 連續答對 3 題 | 1 個寶箱 |
| 連續答對 5 題 | 2 個寶箱 |
| 使用道具 3 次 | 1 個寶箱 |
| 使用道具 5 次 | 1 個寶箱 |

### 持有限制

- 每人最多持有 3 個寶箱。
- 超過 3 個時，系統自動丟棄最早獲得且尚未開啟的寶箱。
- 活動結束未使用寶箱自動失效。

## 寶箱機率

| 獎勵內容 | 機率 |
|---|---:|
| 小加分卡：戰隊 +1 | 30% |
| 中加分卡：戰隊 +3 | 20% |
| 大加分卡：戰隊 +5 | 10% |
| 超級加分卡：戰隊 +10 | 5% |
| 加倍卡 | 5%，每人最多持有或使用 1 次；重複抽到改為大加分卡 |
| 翻身卡 | 10% |
| 挑戰卡 | 10% |
| 特殊道具 | 0%，取消開箱取得，幸運獎改於最後結算抽 1 位 |
| 鼓勵語或空寶箱 | 10% |

## 幸運獎

- 幸運獎全場只有 1 名。
- 特殊道具已取消，不再由寶箱直接抽出。
- 結算時若已有幸運箱開啟紀錄，依紀錄標示得獎者。
- 結算時若無幸運箱開啟紀錄，從現有玩家中指定 1 名幸運獎得主。
- 幸運獎不列入學員端成就系統。

## 全對獎

- 全對獎取 3 名。
- 必須所有正式題目皆已作答且無錯題。
- 若超過 3 人全對，依完成時間排序，取最快完成的前 3 名。
- 學員端不顯示全對獎進度，只顯示是否達成。

## 道具

| 道具 | 效果 | 使用時機 | 限制 |
|---|---|---|---|
| 小加分卡 | 戰隊 +1 | 立即 | 不需選題 |
| 中加分卡 | 戰隊 +3 | 立即 | 不需選題 |
| 大加分卡 | 戰隊 +5 | 立即 | 不需選題 |
| 超級加分卡 | 戰隊 +10 | 立即 | 不需選題 |
| 加倍卡 | 下一題答對時個人分數 x2 | 題前 | 每人最多 1 次，自動套用下一題；重複抽到改為大加分卡 |
| 翻身卡 | 本隊最後一名 +30，否則 +5 | 題後 | 每隊最多觸發 2 次 |
| 挑戰卡 | 猜 0 到 9 整數的大／小，猜中 +10，猜錯 +0，不猜 +3 | 關題關閉後 | 前端依 gameSeed + playerId + itemId + questionId 預先決定答案，不呼叫 GAS；0 到 4 為小，5 到 9 為大 |
| 特殊道具 | 已取消 | 不適用 | 幸運獎改由最後結算抽出 |

## 創作票選題

第 4 版取消創作題與票選流程，避免免費版 GAS 在大量提交與投票時塞車。

1. 題庫以選擇題為主。
2. 學員作答、寶箱、成就與個人道具優先由前端處理。
3. GAS 保留作答去重、排行榜快照、幸運獎、全對獎與賽後報表。

## 0.3.9 規則修正

1. 題庫範例改為 11 題：10 題選擇題、1 題創作題。
2. 創作題只在講師開放創作題時，學員端才顯示創作回答與隊內初選。
3. 講師選出代表作品後，學員端才顯示匿名全體投票。
4. 加分卡改為立即套用戰隊加成，不需要選擇題目。
5. 加倍卡改為使用後自動套用下一題，下一題答對時分數直接乘以 2。
6. 挑戰卡改為猜數字大小，由前端預先決定 0 到 9 整數答案，不呼叫 GAS。
7. 若已經沒有下一題，只能使用加分卡、翻身卡與挑戰卡；加倍卡不可使用。
8. 學員端新增浮動選單，寶箱與成就需點擊後以懸浮視窗開啟。
9. 寶箱或成就有待處理狀態時，功能鈕以紅點提示。
10. 賽後報表功能保留在 GAS API，不在講師 UI 顯示。
11. 排行榜不再分有效人數與戰隊人數，改顯示戰隊人數與答對率。

## 0.3.10 規則修正

1. 加倍卡每位學員只能取得或使用 1 次；重複抽到加倍卡時，系統改給大加分卡。
2. 學員端報到頁不顯示選隊欄位。
3. 講師尚未啟動場次時，學員不可報到。

5. 若開放自由選隊，學員輸入暱稱後以方塊按鈕選隊；若未開放自由選隊，系統直接自動分隊。
6. 同一裝置與同一暱稱重進頁面時，系統讀取既有報到資料，不新增玩家。
7. 排行榜改顯示答對率；未作答、逾時未送出、關題後才作答都視同錯誤。

# 第 4 版測試修正版狀態，0.4.26

`0.4.26` 計分與顯示口徑如下：

1. 個人積分 = 答題得分 + 道具加分。
2. 學員端頂端只顯示「個人積分(答題/道具) 200分（180/20）」，不再另列道具使用分。
3. 個人排行榜依個人積分排序，並顯示總作答秒數。
4. 戰隊積分 = 各題「該題所有作答者答題得分 / 該題參與人數」加總 + 全隊道具加分。
5. 排行榜不顯示答對率。
6. 作答時間為 65 秒；剩餘 65 到 60 秒皆記為 1 秒，剩餘 59 秒起才依 60 秒倒推計算。
7. 投影端開題後顯示答題倒數。
8. 講師可重新開題，已作答學員不可重複送出，未作答學員可補答。
9. GAS 道具加分彙整需依 itemId 去重，避免重複同步造成結算分數偏高。

# 第 4 版測試修正版狀態，0.4.27

`0.4.27` 補充結算與提示規則如下：

1. 最後 1 題關題後、講師按下結算前，學員仍可使用一般加分卡、挑戰卡與翻身卡，GAS 會在結算前同步 pending 道具紀錄並納入最終成績。
2. 加倍卡必須用於下一題；若最後 1 題後才使用，沒有下一題可套用，因此效果為 0 分。
3. 全對獎正式結算後，只顯示正式 `perfect` 獎項，不再把前端候選紀錄 `perfect_candidate` 一起列入公開得獎名單。
4. 空寶箱提示需明確說明沒有取得道具、不扣分、不需再操作。
5. 學員端頂端狀態列只顯示個人積分總分，詳細答題分與道具分以排行榜及後台結算為準。

# 第 4 版測試修正版狀態，0.4.28

`0.4.28` 補充結算前最後道具規則如下：

1. 一般加分卡與挑戰卡在學員端已立即計入個人積分，因此道具紀錄直接顯示「已套用」。
2. 加倍卡與翻身卡需等待下一題或後端確認，因此保留「待套用」到完成套用為止。
3. 講師按下結算後，投影端先顯示 15 秒最後道具使用倒數。
4. 倒數結束後，投影端顯示「講師結算成績中」。
5. 後台實際結算約在講師按下結算後 20 秒執行，保留 5 秒作為最後道具送出與同步緩衝。
