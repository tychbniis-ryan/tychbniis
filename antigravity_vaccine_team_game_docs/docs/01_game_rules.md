# 01 遊戲規則

## 基本設定

| 項目 | 規則 |
|---|---|
| 戰隊數 | 5 隊 |
| 學員人數 | 約 200 人 |
| 主要勝利條件 | 戰隊加權平均分最高 |
| 幸運獎 | 1 名 |
| 全對獎 | 3 名，最快完成且全數答對 |
| 寶箱上限 | 每人最多 3 個 |
| 投票時間 | 60 秒 |

## 戰隊勝利條件

```text
戰隊加權平均分 = 戰隊總得分 / 有效參與人數 + 戰隊任務加成
```

## 答題計分

| 答對時間 | 個人基礎分 |
|---|---:|
| 0-10 秒 | 30 |
| 11-20 秒 | 25 |
| 21-30 秒 | 20 |
| 31-45 秒 | 15 |
| 46-60 秒 | 10 |
| 截止前答對 | 5 |
| 答錯或未答 | 0 |

每題最快答對者可得首答獎勵 +5 分。

## 寶箱

### 取得條件

| 條件 | 獎勵 |
|---|---|
| 每題答對 | 30% 機率取得 1 個寶箱 |
| 正確回答 3 題 | 1 個寶箱 |
| 正確回答 5 題 | 1 個寶箱 |
| 正確回答 10 題 | 2 個寶箱 |
| 連續答對 3 題 | 1 個寶箱 |
| 連續答對 5 題 | 2 個寶箱 |
| 使用道具 3 次 | 1 個寶箱 |
| 使用道具 5 次 | 1 個寶箱 |

### 持有限制

- 每人最多持有 3 個寶箱。
- 超過 3 個時，系統自動丟棄最早獲得且尚未開啟的寶箱。
- 活動結束未使用寶箱自動失效。

## 寶箱機率

| 獎勵內容 | 機率 |
|---|---:|
| 小加分卡：戰隊 +1 | 25% |
| 中加分卡：戰隊 +3 | 20% |
| 大加分卡：戰隊 +5 | 12% |
| 超級加分卡：戰隊 +10 | 5% |
| 加倍卡 | 10% |
| 翻身卡 | 8% |
| 挑戰卡 | 10% |
| 特殊道具 | 3% |
| 鼓勵語或空寶箱 | 7% |

## 幸運獎

- 幸運獎全場只有 1 名。
- 抽中特殊道具者即為幸運獎得主。
- 幸運獎產生後，特殊道具獎池關閉。
- 若完成總題數 70% 後仍未產生幸運獎，特殊道具機率由 3% 提高至 10%，直到產生第 1 名為止。

## 全對獎

- 全對獎取 3 名。
- 必須所有題目皆答對。
- 若超過 3 人全對，依完成時間排序，取最快完成的前 3 名。

## 道具

| 道具 | 效果 | 使用時機 | 限制 |
|---|---|---|---|
| 小加分卡 | 戰隊 +1 | 立即 | 不需選題 |
| 中加分卡 | 戰隊 +3 | 立即 | 不需選題 |
| 大加分卡 | 戰隊 +5 | 立即 | 不需選題 |
| 超級加分卡 | 戰隊 +10 | 立即 | 不需選題 |
| 加倍卡 | 下一題答對時個人分數 x2 | 題前 | 自動套用下一題 |
| 翻身卡 | 本隊最後一名 +30，否則 +5 | 題後 | 每隊最多觸發 2 次 |
| 挑戰卡 | 指定一隊，下一題本隊答對率較高則 +10，否則 +3 | 題前 | 只選戰隊，自動套用下一題，不扣對方分數 |
| 特殊道具 | 取得幸運獎 | 取得即生效 | 全場 1 名 |

## 創作票選題

1. 每位學員提交 1 則答案。
2. 系統依戰隊分流。
3. 同隊學員只能看到自己戰隊投稿池。
4. 隊內初選 60 秒。
5. 每隊產生前 3 名候選答案。
6. 講師每隊選 1 則代表作品。
7. 最終作品匿名為作品 A 至 E。
8. 全體投票 60 秒。
9. 前端隱藏戰隊與暱稱。
10. 後端限制不可投自己隊。

## 0.3.9 規則修正

1. 題庫範例改為 11 題：10 題選擇題、1 題創作題。
2. 創作題只在講師開放創作題時，學員端才顯示創作回答與隊內初選。
3. 講師選出代表作品後，學員端才顯示匿名全體投票。
4. 加分卡改為立即套用戰隊加成，不需要選擇題目。
5. 加倍卡改為使用後自動套用下一題，下一題答對時分數直接乘以 2。
6. 挑戰卡改為使用時只選擇挑戰戰隊，並自動套用下一題結果。
7. 若已經沒有下一題，只能使用加分卡與翻身卡；加倍卡與挑戰卡不可使用。
8. 學員端新增浮動選單，寶箱與成就需點擊後以懸浮視窗開啟。
9. 寶箱或成就有待處理狀態時，功能鈕以紅點提示。
10. 賽後報表功能保留在 GAS API，不在講師 UI 顯示。
11. 排行榜有效人數代表至少完成 1 題已計分作答的人數；報到人數代表完成報到的人數。是否保留有效人數排名，待使用者確認。
