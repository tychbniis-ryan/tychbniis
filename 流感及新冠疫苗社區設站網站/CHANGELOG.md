# Changelog

## [0.63.0] - 2026-07-03

### Changed

- 設站資料表新增 `接種回報時間` 與 `接種回報明細` 欄位，讓「填報日 3 天內修改」與分類明細保存有明確資料依據。
- `updateReport()` 會將分類加總寫回流感／新冠總人數，將分類明細寫入 `接種回報明細`，將使用者輸入備註保留在 `接種回報備註`。
- `修改接種人數` 改依 `接種回報時間` 判斷是否在 3 天內，不再用 `最後更新時間` 代替。
- `ensureSheet_()` 會對既有工作表追加缺少欄位，不刪除、不搬移既有欄位與資料。
- 維護／查詢詳細資料列會顯示接種回報時間、明細與備註，方便後續追蹤。

### Tested

- `npm run test:local`
- GAS `Code.gs` 與 `Index.html` script 語法檢查

## [0.62.0] - 2026-07-03

### Changed

- 民眾端 LINE 使用提示新增獨立關閉按鈕，關閉後本次瀏覽工作階段不再顯示，避免與接種提醒重疊造成看似關不掉。
- GAS 手機首頁改為單欄大按鈕優先，補上 WebView 文字縮放保護與手機版間距，避免在手機中縮成桌機版。
- GAS 回報接種人數改為清冊列呈現，清冊只顯示接種日期、設站地點、行政區與里別；點擊「回報／修改」後才開啟彈出視窗填分類人數。
- 回報彈出視窗依該場次是否提供流感或新冠疫苗動態顯示欄位，送出時仍加總寫回既有總表欄位，分類明細寫入接種回報備註。
- 本機檢查新增 GAS 手機首頁單欄導覽、回報彈窗與民眾端使用提示關閉驗收。

## [0.61.0] - 2026-07-03

### Changed

- 民眾端縮小手機首屏表頭，快速查詢只保留「查詢今日場次」與「查附近接種站」，明日、本週與全部場次移入「進階查詢」。
- 民眾端里別改為關鍵字輸入搭配 datalist；選擇疫苗後可用勾選方式篩選疫苗廠牌。
- 民眾端查詢結果區新增「調整查詢」按鈕，方便使用者跳回篩選條件重新查詢。
- 民眾端接種站卡片將複製場次資訊與分享 Google Maps 位置移到卡片上方小圖示，複製地址移到地址旁，底部只保留「開啟導航」與「查看現場資訊」。
- 民眾端移除範例 `public.json` 場次資料與叫號更新時間顯示，避免正式頁面誤用假資料。
- GAS 新增設站移除必填紅點與暫存轉草稿說明文字，里別改為單一里別加入式輸入，接種日期限制不得早於今天，時間預設上午 08:00 至 12:00。
- GAS 新增設站按鈕改為「送出並公告」、「上傳不公告」、「暫存不送出」，送出並公告會要求主要欄位填寫完整。
- GAS 維護既有資料新增行政區、狀態與關鍵字篩選；查詢場次清冊不再顯示右側維護功能鈕。
- GAS 回報接種人數新增當日、非當日與修改 3 個入口，分類輸入流感與新冠各 3 類後加總寫回總表，分類明細寫入回報備註。
- 廠商配送回報改為輸入「廠商管理密碼」，不再要求廠商查詢碼；系統設定新增「廠商管理密碼」，未填時暫用管理功能密碼。
- 宣導品管理入口可使用管理功能密碼或廠商管理密碼通過驗證，其他管理頁仍維持管理功能密碼。
- 本機檢查腳本同步更新分類回報、Google Maps 導航與新版 RWD 驗收條件。
