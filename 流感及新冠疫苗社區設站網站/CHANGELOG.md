# Changelog

## [0.6.0] - 2026-07-02

### Added

- GAS 後台維護頁新增「編輯資料」操作，可編輯草稿或已解鎖資料。
- 編輯模式沿用 6 步驟表單，儲存時呼叫既有 `updateSite()` 後端函式。
- 編輯模式新增「取消編輯」與「儲存修改」按鈕。

### Changed

- 編輯模式不直接發布草稿；草稿需先儲存修改，再回維護頁按「發布」，確保鎖定與宣導品配送任務流程一致。

## [0.5.0] - 2026-07-02

### Added

- GAS 後台新增設站資料送出前，會依「行政區 + 里別 + 接種日期」提示可能重複資料。
- 重複資料提示提供「仍要新增」與「返回修改」操作。
- 偵測到本機瀏覽器暫存資料時，會提示恢復或清除。
- 各 GAS 後台子頁新增「回到首頁」按鈕。

### Changed

- GAS 後台初始畫面改為只顯示首頁功能入口，需點選功能後才進入子頁。

## [0.4.0] - 2026-07-02

### Added

- 補強 GAS 後台新增設站資料流程，改為 6 步驟填報介面。
- 新增送出前確認摘要，降低填報錯誤。
- 新增前端錯誤摘要，檢查必填欄位、設站時間格式與預估人數整數格式。
- 新增草稿與發布兩種送出按鈕，發布時同步帶入公開狀態。
- 維護列表新增宣導品申請狀態、院所資訊與回報狀態標示。

### Changed

- 首頁功能入口改分為主要作業與管理作業。
- 回報接種人數卡片加強手機填報辨識度。

## [0.3.0] - 2026-07-02

### Added

- 補強民眾端第一版查詢細節。
- 新增 LINE 內建瀏覽器使用提示。
- 新增「分享場次」按鈕，支援 Web Share API，不支援時自動改為複製場次資訊。
- 新增查無資料時的下一步操作：「清除條件」、「查看本週場次」、「查看全部場次」。
- 新增 `docs/PUBLIC_JSON_SPEC.md`，明確定義公開 JSON 欄位與不得輸出欄位。

### Changed

- 民眾端開始套用 `public.json` 的 `defaultView`。
- 修正 `siteId` 網址參數在清除條件後仍持續篩選的問題。
- 補上 `source` 網址參數處理，`source=line` 時顯示 LINE 使用提示。
- 今日已結束場次會在今日場次中排序於後方。
- 範例 `public.json` 改為今日與明日假資料，方便測試今日與明日快捷查詢。

## [0.2.0] - 2026-07-02

### Added

- 補強 GAS 填報端第一版功能骨架。
- 新增維護既有資料、發布、下架、申請解鎖、管理者審核解鎖後端函式。
- 新增回報接種人數、接種率計算與未回報稽催文字產生。
- 新增宣導品品項初始化、接種站發布時自動產生配送任務、非接種站配送任務新增。
- 新增廠商查詢碼登入與配送狀態回報後端函式。
- 新增簡易通知單 CSV 匯出。
- 新增整批新增上限 100 筆的後端函式。
- 將 GAS `Index.html` 改為首頁功能式介面，包含新增、維護、回報、查詢、稽催／統計、宣導品管理、廠商回報與系統工具。
- 新增本機瀏覽器暫存與恢復新增資料草稿。

## [0.1.0] - 2026-07-02

### Added

- 建立民眾端 Firebase 靜態查詢網站骨架。
- 新增 `public/public.json` 範例公開資料。
- 新增行政區、里別、日期、關鍵字、疫苗篩選。
- 新增今日、明日、本週、附近場次快速查詢。
- 新增開啟地圖、複製地址、複製場次資訊功能。
- 新增 GAS 後台 `Code.gs` 與 `Index.html` 骨架。
- 新增 Google Sheet 工作表初始化、設站資料新增、回報、發布、下架、公開 JSON 產生與異動紀錄函式。
- 新增 Firebase Hosting 設定。
- 新增 README、AI 交接文件與版本檔。
