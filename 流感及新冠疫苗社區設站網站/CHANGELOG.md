# Changelog

## [0.27.0] - 2026-07-02

### Added

- GAS 後台 `callGas()` 執行期間會停用按鈕，避免使用者重複點擊造成重複送出。
- 本機檢查腳本新增防重送結構檢查。

## [0.26.0] - 2026-07-02

### Added

- 新增 `scripts/local-check.mjs`，整合 GAS 語法、公開 JSON 與核心邏輯假資料檢查。
- README 與交接文件補上本機一鍵檢查方式，方便承辦人與後續 AI 重複驗證。

## [0.25.0] - 2026-07-02

### Added

- 稽催／統計頁新增宣導品配送完成率。
- 稽催／統計頁新增行政區設站統計，顯示各行政區全部場次、已發布場次與未回報場次。

## [0.24.0] - 2026-07-02

### Added

- GAS 後台新增管理作業入口驗證，進入稽催／統計、宣導品管理與系統工具前需先輸入管理碼。
- 新增 `verifyAdminAccess()`，重用「系統設定」工作表中的管理功能密碼。

## [0.23.0] - 2026-07-02

### Added

- 新增 `里別清冊` 工作表，用於維護需追蹤的行政區與里別。
- 稽催／統計頁新增「里別未設站提醒」，可比對已發布且公開場次並產生未設站里別提醒文字。

## [0.22.0] - 2026-07-02

### Changed

- 校正需求對照表與維運文件，標明 `exportNoticeCsv()` 已將多里別資料拆成單一里別一列輸出。

## [0.21.0] - 2026-07-02

### Added

- 解鎖後修改設站資料時，會同步更新未配送、配送中、異常的接種站宣導品配送任務。
- 新增宣導品品項會自動補建配送任務。
- 取消宣導品品項會將未完成配送任務狀態改為 `取消`，不刪除原始資料。

### Changed

- 配送任務同步只在實際欄位變更時更新最後更新時間與寫入異動紀錄。

## [0.20.0] - 2026-07-02

### Added

- 解鎖申請階段新增已配送宣導品任務檢查。
- 已配送宣導品任務判斷同時比對 `關聯接種站資料ID` 與 `來源資料ID`。

### Changed

- 若接種站已有狀態為 `已配送` 的宣導品配送任務，系統會阻擋申請解鎖與核准解鎖。

## [0.19.0] - 2026-07-02

### Added

- 新增 `docs/REQUIREMENTS_TRACE.md`，對照 4 份開發文件與目前完成狀態。
- 需求對照表標記已具備、部分完成、待實機驗證、待開發與第二版項目。

### Changed

- README 與 AI 交接文件補上需求對照表連結，方便後續開發接續。

## [0.18.0] - 2026-07-02

### Added

- 新增 `docs/OPERATION_GUIDE.md`，整理承辦人日常操作流程、常見狀況與還原方式。

### Changed

- README 與 AI 交接文件補上日常操作手冊連結，方便非工程背景人員維運。

## [0.17.0] - 2026-07-02

### Added

- 新增 `docs/GAS_TEST_CHECKLIST.md`，整理 GAS、Google Sheet、宣導品、廠商回報、公開 JSON 與民眾端實機測試流程。

### Changed

- README 與 AI 交接文件補上 GAS 實機測試清單連結，方便後續驗收與交接。

## [0.16.0] - 2026-07-02

### Added

- GAS 後台維護頁新增解鎖申請表單。
- 解鎖申請表單會帶入資料ID與場次摘要，並檢查解鎖申請人必填。

### Changed

- 維護頁申請解鎖由 `prompt()` 改為頁面內表單，方便填報人送出前確認申請場次。

## [0.15.0] - 2026-07-02

### Added

- GAS 後台廠商配送回報頁新增頁面內回報表單。
- 廠商回報表單可維護配送狀態、實際配送數量、實際配送日期、物流方式、物流單號、廠商回報人與備註。
- 廠商回報送出前會檢查必要欄位與實際配送數量格式。

### Changed

- 廠商配送回報由 `prompt()` 改為結構化表單，降低手機與現場操作時漏填風險。

## [0.14.0] - 2026-07-02

### Added

- GAS 後台宣導品管理頁新增配送任務修改表單。
- 配送任務修改表單可維護配送狀態、配送數量、配送日期、廠商資訊、物流資訊與備註。
- 配送任務修改送出前會檢查配送數量是否為 0 或正整數。

### Changed

- 宣導品配送任務修改由連續 `prompt()` 改為頁面內結構化表單，降低填錯或漏填風險。

## [0.13.0] - 2026-07-02

### Added

- GAS 後台宣導品管理頁新增分頁架構：配送任務、非接種站配送、品項管理。
- 品項管理分頁可檢視啟用中的宣導品品項，並提供建立或檢查工作表入口。

### Changed

- 非接種站配送任務新增表單移入獨立分頁，避免與配送任務列表混在同一操作區。

## [0.12.0] - 2026-07-02

### Added

- 新增 `updateDeliveryTask()` 後端函式，可修改配送任務有限欄位。
- 宣導品管理頁配送任務卡片新增「修改」與「取消任務」操作。
- 配送任務修改與取消會寫入異動紀錄。

### Changed

- 宣導品配送任務取消採狀態改為 `取消`，不刪除原始資料。

## [0.11.0] - 2026-07-02

### Added

- GAS 後台查詢頁新增里別、日期區間、設站地點、承接醫療院所、服務對象、疫苗廠牌、是否公開、回報狀態與宣導品配送狀態篩選。
- 新增查詢條件清除按鈕。
- 後端 `listSites()` 支援上述查詢條件。

### Changed

- 後端統計與查詢共用回報狀態判斷規則。
- 關鍵字搜尋範圍納入流感與新冠疫苗廠牌。

## [0.10.0] - 2026-07-02

### Added

- GAS 後台回報接種人數頁新增預估人數顯示。
- 回報接種人數成功後顯示本次回報摘要。
- 接種人數超過預估人數時，前端會提示確認後仍可送出。

### Changed

- 回報接種人數若輸入非數字，前端會阻擋送出並提示修正。

## [0.9.0] - 2026-07-02

### Added

- GAS 後台新增頁加入整批上傳區塊。
- 支援貼上含表頭的 TSV 或簡易 CSV 資料。
- 整批上傳前端會檢查必要欄位、時間格式、人數格式與 100 筆上限。
- 整批送出會呼叫既有 `bulkCreateSites()` 後端函式。

### Changed

- 整批上傳預設將未指定狀態的資料設為草稿、不公開、不申請宣導品。

## [0.8.0] - 2026-07-02

### Added

- GAS 後台「稽催／統計」頁新增解鎖審核區塊。
- 解鎖審核可顯示待審核申請，並提供「核准解鎖」與「退回申請」操作。
- 審核操作會要求管理碼與審核人，並呼叫既有 `reviewUnlock()` 後端函式。

### Changed

- 維護卡片新增解鎖申請狀態標籤，方便管理者快速辨識待審核資料。

## [0.7.0] - 2026-07-02

### Added

- GAS 後台新增設站資料第 5 步改為宣導品啟用品項勾選與數量輸入。
- 宣導品申請會依 `getAppData()` 回傳的 `deliveryItems` 動態產生品項。
- 申請宣導品時新增前端檢查：至少 1 個品項、數量需為 1 以上整數、配送聯絡資訊需填寫。

### Changed

- 宣導品勾選結果送出前會轉回既有欄位 `宣導品申請品項` 與 `宣導品申請數量`，避免調整 Google Sheet 欄位結構。
- 暫存與編輯資料流程會同步保存與還原宣導品勾選狀態。

## [0.6.0] - 2026-07-02

### Added

- GAS 後台維護頁新增「編輯資料」操作，可編輯草稿或已解鎖資料。
- 編輯模式沿用 6 步驟表單，儲存時呼叫既有 `updateSite()` 後端函式。
- 編輯模式新增「取消編輯」與「儲存修改」按鈕。

### Changed

- 編輯模式不直接發布草稿；草稿需先儲存修改，再回維護頁按「發布」，確保鎖定與宣導品配送任務流程一致。

## [0.5.0] - 2026-07-02

### Added

- GAS 後台新增設站資料送出前，會依「行政區 + 里別 + 接種日期」提示可能重複資料。
- 重複資料提示提供「仍要新增」與「返回修改」操作。
- 偵測到本機瀏覽器暫存資料時，會提示恢復或清除。
- 各 GAS 後台子頁新增「回到首頁」按鈕。

### Changed

- GAS 後台初始畫面改為只顯示首頁功能入口，需點選功能後才進入子頁。

## [0.4.0] - 2026-07-02

### Added

- 補強 GAS 後台新增設站資料流程，改為 6 步驟填報介面。
- 新增送出前確認摘要，降低填報錯誤。
- 新增前端錯誤摘要，檢查必填欄位、設站時間格式與預估人數整數格式。
- 新增草稿與發布兩種送出按鈕，發布時同步帶入公開狀態。
- 維護列表新增宣導品申請狀態、院所資訊與回報狀態標示。

### Changed

- 首頁功能入口改分為主要作業與管理作業。
- 回報接種人數卡片加強手機填報辨識度。

## [0.3.0] - 2026-07-02

### Added

- 補強民眾端第一版查詢細節。
- 新增 LINE 內建瀏覽器使用提示。
- 新增「分享場次」按鈕，支援 Web Share API，不支援時自動改為複製場次資訊。
- 新增查無資料時的下一步操作：「清除條件」、「查看本週場次」、「查看全部場次」。
- 新增 `docs/PUBLIC_JSON_SPEC.md`，明確定義公開 JSON 欄位與不得輸出欄位。

### Changed

- 民眾端開始套用 `public.json` 的 `defaultView`。
- 修正 `siteId` 網址參數在清除條件後仍持續篩選的問題。
- 補上 `source` 網址參數處理，`source=line` 時顯示 LINE 使用提示。
- 今日已結束場次會在今日場次中排序於後方。
- 範例 `public.json` 改為今日與明日假資料，方便測試今日與明日快捷查詢。

## [0.2.0] - 2026-07-02

### Added

- 補強 GAS 填報端第一版功能骨架。
- 新增維護既有資料、發布、下架、申請解鎖、管理者審核解鎖後端函式。
- 新增回報接種人數、接種率計算與未回報稽催文字產生。
- 新增宣導品品項初始化、接種站發布時自動產生配送任務、非接種站配送任務新增。
- 新增廠商查詢碼登入與配送狀態回報後端函式。
- 新增簡易通知單 CSV 匯出。
- 新增整批新增上限 100 筆的後端函式。
- 將 GAS `Index.html` 改為首頁功能式介面，包含新增、維護、回報、查詢、稽催／統計、宣導品管理、廠商回報與系統工具。
- 新增本機瀏覽器暫存與恢復新增資料草稿。
