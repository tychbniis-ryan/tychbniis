# 開發文件需求對照表

本文件用於對照 4 份開發文件與目前專案狀態。狀態定義如下：

1. `已具備`：已有程式或文件支援，且本機語法檢查通過。
2. `部分完成`：已有骨架或主要流程，但仍缺部分規則、欄位或完整 UI。
3. `待實機驗證`：本機無法驗證，需在 Google Apps Script、Google Sheet 或 Firebase 實際環境測試。
4. `待開發`：尚未實作。
5. `第二版`：開發文件列為後續優化或第一版明確不納入。

## 5. 目前最重要缺口

### 5.1 需優先補程式的缺口

目前第一版主要程式缺口已補齊，後續以實機驗證與第二版功能為主。

### 5.2 需優先實機驗證的缺口

1. `setupWorkbook()` 是否正確建立所有表頭。
2. `createSite()`、`publishSite()`、`updateSite()` 寫入與異動紀錄。
3. 發布產生配送任務、防重複配送任務。
4. 已配送宣導品任務是否正確阻擋解鎖申請與核准解鎖。
5. 解鎖後修改設站資料是否正確同步未完成配送任務。
6. 通知單 CSV 多里別資料是否正確拆成單一里別一列。
7. 里別清冊是否正確產生未設站提醒。
8. 管理作業入口是否正確要求管理碼，廠商配送回報是否不受影響。
9. 稽催／統計頁的配送完成率與行政區統計是否正確。
10. `buildPublicJson()` 實際輸出是否符合 `PUBLIC_JSON_SPEC.md`。
11. 廠商登入與配送回報。
12. 民眾端手機、LINE、定位、地圖、分享與 URL 參數。

### 5.3 可列第二版的項目

1. 語音搜尋。
2. 正式 Google 帳號權限控管。
3. 完整圖表儀表板。
4. 完整 Excel 匯入與匯出。
5. 匿名流量統計。
6. 大量 QR Code 產製。
7. 機關正式子網域。
